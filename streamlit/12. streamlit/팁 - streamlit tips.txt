1. streamlit 환경설정
기본적으로 anaconda의 base를 사용한다. 여기에 설치되어 있다. 
그래서 가끔 vscode에서 이 base를 못 읽는 경우가 있는데, 해당하는 path를 시스템 변수로 설정해 주어야 한다. 
그러면 powershell이던, command 창이던 다 읽을수 있다.

환경변수- 시스템 변수 - Path
anaconda의 path를 설정해 주어야 한다.
C:\Users\User\anaconda3\Scripts
C:\Users\User\anaconda3\Library\bin
C:\Users\User\anaconda3\

설정하고 재시작하고, anaconda 실행하고, vscode 실행한다.



2. 기본 streamlit 문법 

import streamlit

<텍스트 출력>

.title : 텍스트를 타이틀로 출력 (제일 큰 글씨)
.header : 텍스트 헤더로 출력 (타이틀보다 작음)
.subheader : 텍스트를 서브헤더로 출력 (평소보다 약간 큼)
.text : 텍스트 출력 (평소 보는 글씨 크기)

<안내 텍스트박스 출력>

특정 상황에 따른 텍스트박스를 출력

.success : (녹색)작업이 정상적으로 작동 했을 때 사용
.warning : (노란색) 경고 문구를 보여주고 싶을 때 사용
.info : (파란색) 정보를 보여주고 싶을 때 사용
.error : (빨간색) 문제가 발생 했을 때 사용

2. 두개 이상의 파이썬 파일을 구동하고 싶은 경우는?
다른거랑 똑같음. streamlit이라고 다른것이 아님.
import한 후에, 해당하는 파일의 함수를 부르면 됨.

# 두번째 페이지
import streamlit as st

def run_home() :
    st.subheader('홈 화면입니다')
    st.text('파일 분리 앱 테스트')


#첫 페이지

import streamlit as st
import second_page

def main() :
    st.title(' 파일 분리 앱 ')
    menu = ['Home', 'EDA', 'ML', 'About']
    choice = st.sidebar.selectbox('메뉴', menu)

    if choice == menu[0] :
        second_page.run_home()
